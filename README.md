# TRANSFORMERS: Battle for Cybertron

2D-аркадный файтинг в браузере: автоботы против десептиконов. Весь код игры — один файл `index.html`, без зависимостей и без сборки.

## Играть

```bash
npm start          # http://localhost:3000
```

Или просто открыть `index.html` в браузере.

## Персонажи

| Боец | Фракция | Альт-форма | Особенность |
|---|---|---|---|
| Оптимус Прайм | Автобот | Фура | Крепкий (110 HP), тяжёлый урон |
| Бамблби | Автобот | Спорткар | Самый быстрый, высокий прыжок |
| Мегатрон | Десептикон | Танк | Максимальный урон, 112 HP |
| Старскрим | Десептикон | Джет | Летает в альт-форме |
| Саундвейв | Десептикон | Дрон | Стреляет вдвое чаще |

## Механика

- **Трансформация.** Робот — удары, блок, прыжок. Транспорт — скорость ×1.7, таран и выстрел, но без блока и прыжка.
- **Энергон.** Копится от полученного и нанесённого урона. На 100% доступен суперудар с неуязвимостью на активных кадрах.
- Матч до 2 побед, раунд 60 секунд, три уровня сложности ИИ.

## Управление

**Клавиатура:** `A`/`D` — движение, `W` — прыжок (у джета — тяга вверх), `S` — блок, `J` — быстрый удар (таран), `K` — тяжёлый удар (выстрел), `ПРОБЕЛ` — трансформация, `L` — суперудар, `ENTER` — подтвердить.

**Планшет/телефон:** экранные кнопки появляются автоматически на сенсорных устройствах. Навигация по меню — тапом. Кнопка `⛶` разворачивает на весь экран. Для проверки тач-режима на компьютере: `index.html?pad=1`.
